- Inverted the visibility setting for the secondary panel.

## [1.0.1+fabric-1.21.11] - 2026-02-19

### Added
- Added a new section to the secondary panel showing weather and biome information.

### Changed
- Migrated to the official Minecraft mappings for future compatibility with unobfuscated versions of the game.
- Removed broken position settings that conflicted with the new biome/weather panel and vanilla F3 reduced-info view.

### Fixed
- Handled the new reduced debug info screen from vanilla Minecraft so the panel still renders when an item is pinned.
